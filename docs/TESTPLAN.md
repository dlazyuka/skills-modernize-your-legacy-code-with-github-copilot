# COBOL Account Management Test Plan

These cases characterize the current COBOL implementation and identify behavior that needs business confirmation. Unless a case says otherwise, start a fresh program process with its initial balance of `1000.00`. Record actual outcomes when running the cases. Items marked for confirmation are not approved business requirements until stakeholders decide the intended behavior.

## Migration Test Notes

- Use ACCT-001 through ACCT-011 and ACCT-016 as functional integration scenarios across the menu, operations, and balance storage. Extracted business functions in the Node.js app can have focused unit tests for credit arithmetic, debit eligibility, and unchanged balance on rejection.
- Treat ACCT-013 through ACCT-015 and the zero-amount rule in ACCT-008 as characterization and stakeholder-decision cases. Do not encode runtime-dependent COBOL behavior as a Node.js requirement without agreement.
- Fill in Actual Result and change Status to Pass or Fail when each case has been executed and reviewed.
